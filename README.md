<h1 align="center">Finition</h1>

**Financial Business Tracker & Auto Invoicing App**

[![Platform](https://img.shields.io/badge/Platform-Android-green.svg)](https://developer.android.com/)
[![Language](https://img.shields.io/badge/Language-Kotlin-blue.svg)](https://kotlinlang.org/)
[![License](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

Finition is a streamlined mobile application built with Kotlin, designed to empower freelancers and small-to-medium business owners. It combines intuitive financial tracking with automated invoicing capabilities to reduce administrative overhead and improve financial oversight.

## 🚀 Key Features

*   **Comprehensive Financial Tracking:** Easily log income and expenses with customizable categories.
*   **Visual Dashboard:** Get a clear overview of your financial health, including cash flow, profit/loss statements, and expense breakdowns.
*   **Auto Invoicing:** Generate professional, customizable invoices automatically based on your tracked projects or manual entries.
*   **Invoice Management:** Send invoices directly, track payment statuses in real-time, and maintain a complete history.
*   **Smart Notifications:** Receive timely reminders for overdue invoices and alerts for important financial milestones.

## 💰 Currency Support

> **Note:** The application currently supports **US Dollar (USD)** only.

## 🎯 Who is this for?

*   **Freelancers:** Automate billing for completed projects and save hours on administrative tasks.
*   **Small Business Owners:** Make informed decisions with clear monthly income and expense overviews.
*   **Non-Accountants:** A user-friendly interface that requires no prior accounting expertise.

## 🛠️ Tech Stack

*   **Language:** Kotlin
*   **Platform:** Android (Native)
*   **Package ID:** `com.finition.app`
*   **Key Integrations:** Email services, Cloud storage for backups, and Payment gateway APIs.

## 📥 Installation

### Option 1: GitHub Releases (APK)
1. Go to the [Releases page](https://github.com/username/finition-app/releases).
2. Download the latest `.apk` file.
3. Enable "Install from Unknown Sources" in your Android settings if prompted.
4. Open the downloaded file to install.

### Option 2: Build from Source
1. Clone the repository:
   ```bash
   git clone https://github.com/username/finition-app.git
   ```
2. Open the project in **Android Studio**.
3. Sync Gradle files and run the app on an emulator or physical device.
